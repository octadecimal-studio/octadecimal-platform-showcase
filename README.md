# Octadecimal Platform Showcase

Sanitized public mirror of a private production repository. The goal of this
repository is to show implementation history and architecture choices without
publishing private client data, environment files, credentials, uploaded media,
database backups, or deployment details.

## What This Demonstrates

- Laravel application structure with Filament resources and Livewire fixes
- GraphQL API work with Lighthouse schema files
- TypeScript/Node tooling around MCP servers and automation helpers
- Docker, NGINX, PHP and CI-oriented local infrastructure
- Tailwind, PostCSS, Vite and Axios usage in the Laravel frontend pipeline
- Preserved Git history for the retained source paths, including dated commits
  and merge commits from the original private project

## Sanitization Notes

This mirror intentionally excludes private notes, assets, uploads, database
backups, environment files, generated frontend bundles and client-specific
deployment instructions. Some internal names may remain in commit messages
because they are part of the historical record, but the retained tree is meant
to be safe for public portfolio review.
